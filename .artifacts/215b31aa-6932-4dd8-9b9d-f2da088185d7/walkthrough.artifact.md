# Огляд реалізації додатку "Збірник карток клієнтів"

Я реалізував основний каркас додатку згідно з вашими вимогами.

## Що було зроблено:

### 1. Архітектура та Дані
- **Room Database:** Налаштовано збереження клієнтів, їх телефонів та нотаток.
- **Відносини:** Клієнт може мати безліч номерів телефонів та нотаток.
- **ViewModel:** Логіка пошуку та управління даними реалізована через MVVM.

### 2. Інтерфейс (UI)
- **Головний екран:** Список клієнтів з миттєвим пошуком та стильними картками Material 3.
- **Екран деталей:**
    - Додавання фото магазину (через галерею).
    - Динамічні поля для телефонів (можна додавати скільки завгодно).
    - Поля для імені, прізвища та назви магазину.
    - Секція приміток (можна додавати текстові замітки).
- **Налаштування:** Перемикач День/Ніч (Темна тема).

### 3. Навігація
- Використано **Navigation Compose** для переходу між списком, деталями та налаштуваннями.

## Як користуватися:
1. На головному екрані натисніть **"+"**, щоб створити нового клієнта.
2. Введіть дані, додайте фото та номери телефонів.
3. Натисніть **"Зберегти"** (іконка дискети зверху).
4. Використовуйте рядок пошуку для швидкого знаходження клієнта за іменем або назвою магазину.

## Наступні кроки (можна додати пізніше):
- Інтеграція Google Maps для точного вибору координат.
- Голосові замітки (Record Audio API).
- Нагадування через AlarmManager.
